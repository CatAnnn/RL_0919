# 缺失参数反推：预先声明的诊断协议

本次用户明确要求从论文实验反推未公开参数。本目录属于逆问题诊断，允许计算条件估计与可行域；不属于真实训练，不替代原实验，也不把读图值注入训练、奖励或动作。原配置、数据、日志、检查点与主图保持不变。

1. 从原PDF提取图5—9的嵌入图像，保留来源哈希。图6—8按原图轴刻度读取24个功率与失衡值；横轴0对应表II第1小时。采用保守读图误差：CG ±0.5 kW、BA ±0.15 kW、失衡 ±1 kW；图9失衡 ±50 kW、CG/BA成本 ±500美元。它们是读图容差，不是统计置信区间。
2. 先交叉核对图6—8的物理平衡及CG成本与图9，判断能否将各图视作同一轨迹。不能通过调整原表输入消除矛盾。
3. 奖励权重使用式16的线性约束。图5与图9不同迭代只做明确标记的同阶段条件配对；设奖励另有5%协议容差并检查零容差、20%容差敏感性。价格加权失衡不能用未加权失衡直接代替。先求非负、各≤1的可行集合，再讨论候选值；不强加权重和为1。
4. 电池容量和初始SOC使用图6—8的带符号功率序列，按物理效率解释求所有时刻SOC可行条件。分别报告[0,1]及[0.1,0.9]、效率1及0.95，显式考虑0.002自放电。首小时耗尽假设另列，不能当作已观察到的事实。读图误差以逐点区间传播。
5. MG1 CG内点动作仅在“完全信息且该小时可独立优化”的额外假设下用一阶条件估计权重比；若各小时冲突，则否定该解释，不能挑选小时。
6. 对网络结构与PPO内循环作可辨识性检查，包括等价网络构造、单步PPO对clip的不敏感性。常见超参数只是后续可运行假设，不能从收敛速度直接认定。
7. SOC效率分支用能量收支验证；Critic平方误差的正负梯度用固定TD目标的可复算例子验证。区分修正的数学合理性与作者实际实现。
8. 本轮不启动新RL训练。输出可运行分析脚本、数字化参考CSV、条件可行域/反例证据及中文报告。所有推断覆盖七项目标；无法唯一恢复时给出原因和所缺观测，不伪称作者参数已恢复。
